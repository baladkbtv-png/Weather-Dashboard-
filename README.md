# 🌤️ Google Weather Dashboard

A responsive, feature-packed Weather Dashboard inspired by Google Weather UI, built with pure HTML, CSS, JavaScript, and powered by Open-Meteo APIs.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-live-brightgreen.svg)

## ✨ Features

- 🎨 **Dynamic Animated Themes**: Real-time canvas particles for rain, snow, and theme shifts based on weather conditions (Clear, Clouds, Rain, Thunderstorm, Fog, Day/Night).
- 🔍 **Live Search Autocomplete**: Global city/town lookup powered by Open-Meteo Geocoding.
- 📍 **GPS Location Detection**: Auto-detect your location with one click.
- 🌡️ **Unit Switcher**: Toggle effortlessly between °C and °F.
- 📊 **24-Hour & 7-Day Forecasts**: Detailed hourly strip and daily range indicator bars.
- 💨 **Comprehensive Metrics**: Air Quality Index (AQI), UV Index, Wind & Gust Direction Compass, Sun Arc Trajectory, Humidity, Dew Point, Pressure, and Visibility.
- 🔑 **No API Key Required**: Runs 100% free with Open-Meteo public endpoints.
